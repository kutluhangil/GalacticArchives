## 2026-08-05

- Compare rose to the system level: a fourth mode where each column is a star system rather than a world. It states the suns by name and colour, the moon figure canon gives, the moons the archive can name, the stations standing in the selected era, and the primary's diameter, region, sector and allegiance. Canon gives the 81 worlds 81 distinct system names, so a system is not a record of its own — `systemFacts` reads it off the primary body and reports nothing where the record states nothing, which is why Nal Hutta shows a named moon and no count. The schematic above each column is SVG, not a `SystemEngine` scene: four live systems would have cost four WebGL contexts for a picture whose job is to be read at a glance, and every figure it draws is written out in the table below it. The mode now rides in the URL beside the set (`?mode=systems&ids=`), so a system comparison is as shareable as a planet one and switching tabs no longer leaves the previous mode's ids behind. 269 unit and component tests, up from 259, and 30 end-to-end, up from 29.
- The archive's long runs stopped charging a Tab stop per record. The galaxy's keyboard mirror listed all 81 worlds and all 23 lanes as tab stops, so reaching anything under the map meant a hundred presses, and the Holocron's card grids added as many again. Each run now keeps one tabbable entry and the arrow keys move it (`useRovingFocus`): in the grids, down and up hold the column while left and right walk the cards, `Home` and `End` reach the ends, and a filter that swaps the grid hands the resting spot back to the first card. Row geometry only exists where layout does, so the grid walk is asserted in a real browser and the row arithmetic in a unit test. 259 unit and component tests, up from 252, and 29 end-to-end, up from 27.
- First paint came down off its ceiling: 399,500 bytes of a 400,000 budget, with no room for the next feature. The guided-tour player was riding on every first paint while having work to do on almost none of them — through `lib/lore` it carried the station, era, region, faction and production tables, plus the authored itineraries and the lane tour loader. It now loads the first time a tour starts, the same trade the ⌘K palette already made. Entry chunk 346 kB → 308 kB, first paint 399,500 → 361,270 bytes, and the budget ceilings dropped to 330 kB and 390,000 so the win cannot quietly leak back.
- The sector became an axis the archive can actually search. Canon draws no sector borders — 60 sectors across the 71 worlds that name one, most holding a single world — so a polygon layer would have meant inventing geometry. Instead the Holocron gained a counted sector filter (including the worlds canon leaves unplaced) and ⌘K searches sector names, so "Arkanis sector" gathers Tatooine, Geonosis and Trask. Three worlds carried `"None"` or `"N/A"` in that field, which would have shipped as a sector named None; the field is omitted where canon states nothing and `validate-lore` rejects the placeholders.
- The last fabricated field in the transmissions is gone. Each recording printed a precise-looking `audioFrequency` — "1420.405 MHz (Encrypted HoloNet)", "R2-D2 Memory Core 0x9F" — beside a sourced transcript, so invented telemetry read as canon detail. The field is now `channelLabel`: it names the medium the recording travelled on, the player marks it as the archive's own wording, and `validate-lore` rejects a frequency, a hex address or a channel number in it so the fabricated precision cannot come back.
- The two secondary lore widgets caught up with the tool panels. The Holocron quiz drew its own overlay — no dialog role, no Escape, no focus trap — and marked right and wrong answers in border colour alone; it now uses the shared shell and states each verdict in text. The ship blueprint's hotspots lived on bare SVG circles a keyboard could never reach: the schematic is decorative now, and its legend buttons carry the pressed state and announce the opened component. 245 unit and component tests, up from 238.
- The archive's provenance rule now reaches the codex: all 64 starship, battle, Force power, timeline, watch-guide and transmission records cite the Wookieepedia article they were written from, the same way every world and character already did. `scripts/fetch-codex.mjs` resolves each citation against the MediaWiki API and commits the evidence as `test/fixtures/codex-digest.json`; `validate-lore` fails on a record with no citation, a citation Wookieepedia does not have, an in-universe record pointing at a real-world article, and a Legends-only article presented as canon. The Holocron surfaces link the article under each record, which is what the CC BY-SA attribution attaches to.
- Data honesty in the same pass: "Force absorb" and "Tutaminis" were one canon concept written twice (the first redirects to the second), so the duplicate is gone — 15 powers, not 16. Tutaminis and Force storm are documented by Wookieepedia only in Legends and now carry the same gold Legends marking the worlds use. Obi-Wan's Order 66 warning printed a rewritten transcript in quotation marks; it now prints the canon wording from the cited article, and every transcript states whether it is quoted or reconstructed by this archive.
- The four lore routes now produce static pages and sitemap entries of their own (166 → 170 URLs); a crawler used to see only the shell's site-wide title for `/timeline`, `/force`, `/watch-guide` and `/hangar`. The top bar's five tool panels became lazy imports, cutting the chunk that rides on every route from 51.7 kB to 16.9 kB, and the budget now watches that chunk by name.
- Interface sound has a home: the choice persists in `localStorage` and lives as a switch in the settings menu beside Legends and hyperlanes, instead of a header chip that reset to on with every reload.
- Made the new surfaces usable without a mouse. The five tool panels were bare overlay divs — no dialog role, no label, no Escape, and Tab walked straight out of the panel into the map behind it; they now share one shell that labels the dialog by its own heading, moves focus in, keeps Tab inside, closes on Escape or a backdrop click, and hands focus back to whatever opened it. ## 2026-08-02

- Planet surfaces now ship as ETC1S KTX2 rather than WebP: a 4K albedo costs the GPU about 11 MB instead of the 43 MB an RGBA upload took, and the transcode happens off the main thread. The pipeline runs `ktx2-encoder` inside Node instead of shelling out to `toktx`, so any checkout produces the same tiers, and the Basis transcoder finally ships under `public/basis/` — that directory never existed, so the KTX2 path the loader already had would have 404'd. Asset validation reads KTX2 headers for size, mipmap chain and supercompression; the service worker caches the transcoder alongside the textures.
- Profiled the two-second freeze when a world opens and found it is not where the roadmap assumed: JavaScript accounts for ~300 ms of it and the driver for the rest, so slicing the scene build across frames would have bought nothing. The engine now warms up through `renderer.compileAsync`, which hands program compilation to the browser where `KHR_parallel_shader_compile` exists. Headless SwiftShader has no such extension, so CI cannot show the gain; bloom was measured to cost 0.54s of the remaining freeze.
- Three new guided tours: Rogue One's five worlds, the four stops that turn Andor into a rebellion, and the worlds the Sith marked. Six tours in total, each bilingual.
- Retook all six documentation screenshots on a real GPU: the galaxy map shows the hyperlane network, the Holocron shows the generated cards, and the frame counter reads honestly instead of `0 fps`.
- Tidied the repository: every document now lives under `docs/` behind an index, with only `README.md`, `CHANGELOG.md` and `LICENSE` left at the root. `docs/kalan-isler.md` replaces the two overlapping handover notes and states what is done, what needs the owner (Developer ID signing) and what is still mine. Deleted the superseded `PLAN.md`, `design.md`, `HANDOFF.md`, `SENDEN-GEREKENLER.md`, the Vite template `app/README.md`, the Kimi leftover `app/info.md` and the 15 stale working shots under `screenshots/`; the visual-prompt inventory and the roadmap now read as finished where the work is finished.
- Fixed the red CI: a world's panel now paints before its globe is built. Building the planet scene blocks the main thread for ~2s locally and far longer on a two-core runner, and a blocked thread answers no queries, so the three deep-link end-to-end tests timed out at the default 5s. The scene build moved behind the panel's first paint (the record is readable ~325ms sooner), and the WebGL-route assertions got the same 20s window the galaxy tests already used. CI also writes the Playwright HTML report and keeps `test-results`, so the next failure ships its traces instead of an empty artifact.
- Fixed the Vercel production deployment: the project had no Root Directory set, so `npm run build` ran from the repo root and died with `ENOENT /vercel/path0/package.json` on every deploy since 2026-07-31, leaving the live site stuck on an old build. Root Directory is now `app`, the deploy is green again and serves the same bundle as a local build. Recorded the requirement in the README stack summary and gitignored the local `.vercel` link directory.
